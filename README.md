# acpp63
Site vitrine officiel d'ACPP (Atelier CastelPontin du Plastique, Pont-du-Château) : usinage et façonnage plastique pour l'industrie, les musées et l'enseigne. Publié sur acpp63.fr.

## Photos (v5)
Dossier `img/` : chaque photo existe en deux tailles, `nom.jpg` (1600 px, ~250 Ko, affichée en plein écran) et `nom-800.jpg` (vignettes des galeries).
Sources : photothèque Dropbox ACPP et réalisations SPC Enseignes. Aucune image issue d'Internet.
Pour ajouter une photo : l'exporter aux deux tailles, puis copier un bloc `<figure>` d'une galerie existante.
